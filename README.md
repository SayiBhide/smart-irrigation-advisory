# AI-Based Smart Irrigation Advisory System

## Project Overview

An AI-based multi-crop irrigation advisory system that uses
machine learning and weather forecasting to provide irrigation
recommendations.

## Technologies Used

- Python
- Streamlit
- XGBoost
- Scikit-learn
- Pandas
- OpenWeather API

## Machine Learning Models

- Random Forest
- Decision Tree
- XGBoost
- SVM

XGBoost was selected as the final model based on comparative
evaluation.

## Dataset

10,000 agricultural records from Uttarakhand covering:

- Rice
- Maize
- Sugarcane
- Potato
- Wheat
- Cotton
